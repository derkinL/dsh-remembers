# 功能：人味后处理（`tone_fix`）

纯规则函数，不调模型，同输入同输出。给她一个「顺手把话捋一遍」的工具，而不是让她每句都靠提示词硬压。

## 做什么

| 规则 | 输入 → 输出 |
|---|---|
| 压重复标点 | `有点拖。。` → `有点拖。` |
| 压感叹/问号 | `好！！！！` → `好！`；`为什么？？？？？` → `为什么？？？` |
| 破折号换逗号 | `配乐不错——就是有点拖` → `配乐不错，就是有点拖` |
| 句尾尾巴（可选） | `cute`：呀/嘛/啦/哟/哦/呢；`abstract`：典/绝了/离谱/这很难评/就这 |

只挑**判断句**下手（含「有点/挺/太/真的/感觉/觉得/拖/尬」），整段最多一处；代码块、表格、引用、列表、行内代码、URL、数字结尾一律不动。

## 文件树

```
tools/tone.js                 # 全部规则 + fixTone()
index.mjs                     # tone_fix 工具注册（唯一调用方）
tests/node/tone.test.mjs      # 断言集（含「不动代码块/表格/数字结尾」）
```

## 已知边界

- 只在模型主动调 `tone_fix` 时生效，不拦截输出（拦截会改掉她自己想说的话）。
- 尾巴是可选参数；不传就不加。
- 规则维护在 `tools/tone.js` 顶部常量里，新增规则要同时补 `tests/node/tone.test.mjs`。
